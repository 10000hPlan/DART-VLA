# DART-VLA

**Depth-Augmented and Reinforcement-Tuned Vision-Language-Action Policies**

Yifei Hu, Shuai Li, Rui Zou, Shengyu Zhao, and Jie Liu.

## Project website

[Visit the DART-VLA project website](https://10000hplan.github.io/DART-VLA/)

## Real-world demonstration

[Watch or download the insulator grasping and placement video](insulator-grasp.mp4).

The video is shown at **5× real-time speed**.

The physical-robot study evaluates supervised depth augmentation using task-specific demonstrations. Reinforcement tuning is evaluated in simulation.
