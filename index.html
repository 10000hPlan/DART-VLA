Research overview

Geometric cues for
robot manipulation.

DART-VLA is a depth-augmented and reinforcement-tuned framework for flow-based vision-language-action policies. It combines monocular geometric priors with reward-guided optimization to improve robot manipulation.

Identity-start depth modulation adds spatial structure while preserving the pretrained token distribution. In simulation, stochastic flow rollouts enable reinforcement tuning, while evaluation retains deterministic action generation. Experiments cover LIBERO, MetaWorld, and supervised real-world UR5 insulator manipulation.

Method

From depth to action

01 / PERCEPTION

Monocular depth priors

Depth features supplement RGB observations with spatial-geometric cues for manipulation.

02 / INTEGRATION

Identity-start DepthFiLM

Feature-wise modulation introduces depth conditioning while preserving the initial behavior of the pretrained backbone.

03 / OPTIMIZATION

FlowPO reinforcement tuning

Reward-guided stochastic flow rollouts refine policies in simulation, with deterministic Euler action generation at evaluation.
